# Uli Ecosystem：可复利的产品体系

每个 Uli 产品都是独立仓库。Profiliuli 只负责生态叙事，并链接到工程证明。

## 为什么这样拆

- 品牌站与产品代码解耦
- 访客路径清晰：故事 → 产品 → 仓库
- 计划中或 MVP 阶段的产品可以诚实标注，而不假装已完全交付

## 生命周期诚实原则

| 生命周期 | 含义 |
| --- | --- |
| Active | 长期主线 |
| MVP | 验证核心能力 |
| Maintained | 保持可用、轻度同步 |
| Merged | 能力已迁移；仓库保留作证明 |

诚实的状态标注，胜过夸大的 Demo 清单。
