# 使用 Tauri 构建跨平台桌面应用

## 引言

Tauri 是一个使用 Web 技术构建桌面应用的框架。它是 Electron 的优秀替代品，提供更小的打包体积和更好的性能。

## 为什么选择 Tauri？

- **更小的打包体积**：Tauri 应用通常比 Electron 应用小得多
- **更好的性能**：使用 Rust 后端实现原生性能
- **安全性**：内置安全考虑
- **跨平台**：支持 Windows、macOS 和 Linux

## 开始使用

```bash
npm create tauri-app@latest
```

## 结论

Tauri 是构建现代桌面应用的绝佳选择。
