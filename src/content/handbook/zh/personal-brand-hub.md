# 为什么 Profiliuli 是个人品牌中心

Profiliuli 不是产品目录。它回答的是另一类问题：**我是谁、我构建什么、我如何思考**。

## 分层体系

- **GitHub Profile** — 30 秒技术名片
- **Profiliuli** — 个人品牌中心
- **Uli Ecosystem** — 产品组合
- **Handbook** — 思想沉淀
- **Repositories** — 工程证明

## 边界原则

产品实现文档留在各产品仓库；长文思考与对外文章放在 Handbook。

```text
GitHub Profile → Profiliuli → Projects / Handbook → Product Repositories
```

每一层只做一件事，访客才知道下一步该去哪里。
