# Why Profiliuli is a Personal Brand Hub

Profiliuli is not a product catalog. It answers a different question: **who I am, what I build, and how I think**.

## Layered system

- **GitHub Profile** — technical cover in 30 seconds
- **Profiliuli** — personal brand hub
- **Uli Ecosystem** — product portfolio
- **Handbook** — thinking artifacts
- **Repositories** — engineering proof

## Boundary rule

Product implementation docs stay in product repos. Long-form thinking and essays live here in Handbook.

```text
GitHub Profile → Profiliuli → Projects / Handbook → Product Repositories
```

Keep each layer focused so visitors always know the next place to go.
