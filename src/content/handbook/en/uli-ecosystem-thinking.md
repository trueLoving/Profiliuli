# Uli Ecosystem as Compounding Products

Each Uli product is an independent repository. Profiliuli only presents the ecosystem narrative and links to proof.

## Why this structure

- Lower coupling between brand site and product code
- Clear visitor paths from story → product → repository
- Room for planned or MVP products without pretending they are fully shipped

## Lifecycle honesty

| Lifecycle | Meaning |
| --- | --- |
| Active | Long-term mainline |
| MVP | Validating core capability |
| Maintained | Keep available, sync lightly |
| Merged | Capabilities moved; repo kept as proof |

Honest status beats inflated demo lists.
